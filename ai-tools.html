01 / How I work

How I work with AI

I use AI every day, but the idea always comes first. It helps me create things I could never film, like full stadiums, crowds and 3D characters, and it takes care of the repetitive parts of production so I have more time for the creative work.

  • Figma Weave
  • Claude Code
  • After Effects
  • Figma
  1. ConceptI start with the hook and the story. What should people feel in the first second, and what makes them watch until the end?
  2. GenerateI build node-based workflows in Figma Weave where image and video models are connected in one graph, and reuse the graph for the next campaign.
  3. CraftI composite, animate, add type and edit everything by hand in After Effects, with the brand’s own elements, legal text and safe zones.
  4. ScaleI design the original, then Claude scales it. One agent per brand builds from my templates, and a reviewer agent checks every card against my originals before I see anything.
02 / Systems

Tools I built

Four brands, new games every week and every ad in many formats is too much to do by hand. So I built my own production tools with Claude Code. They handle the repetitive parts, I make the creative calls and review everything that goes out.

  • Claude Code
  • Codex
  • Python
  • Apps Script
  • Creative StudioTemplates and an editor for Meta creative across all four brands. Replaced Figma for our Meta ads.~6 700 Meta images and videos
  • Thumbnail StudioBuilds game thumbnails for every brand: fetches the assets, picks the motif, makes every size and names the files.6 000+ thumbnails
  • Programmatic StudioRenders transparent game videos in four banner formats without After Effects, and checks every file automatically before it goes to Bannerflow.Six games in one day
  • Streamer panelAn After Effects panel: cut a stream once in 16:9 and it builds the 9:16 split and endcard for every clip.A new streamer week in minutes
  • CRM StudioCRM banners and tournament images built from each game’s own assets.Tournaments without Figma
  • Campaign BuilderMeta creative, campaigns and results in one sheet, shared with the performance team.Creative and numbers in one place
